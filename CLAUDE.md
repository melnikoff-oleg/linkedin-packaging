# LinkedIn Packaging

Read [AGENTS.md](AGENTS.md), then [docs/agent-workflow.md](docs/agent-workflow.md). These are this project's operating instructions for Claude Code as well as Codex.

Handle the technical work yourself. The person's workflow is: open the project → connect all three API keys privately in `.env` → paste their brief → compare all 10 styles together in the localhost preview and refine a favorite. Follow the API setup instructions in the runbook, preserving existing `.env` values. Generate all 10 initially; do not ask for an upfront style choice. Do not send them to a terminal or require GitHub. Ask only for missing facts, a usable photo or a private correction to a missing/invalid key. Deliver upload files and editable sources after review.
