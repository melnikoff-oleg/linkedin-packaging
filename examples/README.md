# Public visual examples

Open `index.html` to browse two profiles across ten styles, compare original-profile reconstructions, and download each final banner, portrait, headline and preview. The gallery is fully local and uses system fonts.

- `kayla-np-digital/results/` contains the final NP Digital adaptations.
- `emily-padres/results/` contains the final San Diego Padres adaptations.
- Each style includes unchanged `banner.png`, `portrait.png`, `preview.png`, and `headline.txt`, plus native desktop/mobile review PNGs.
- WebP review images are lossless conversions for a fast gallery.
- Each `before/` folder reconstructs the saved original profile in the same preview layout. Kayla retains her original skyline banner. Emily’s saved profile has no banner URL or source banner, so a neutral cover is explicitly labeled.
- `provenance.json` records original headlines, profile attribution, source asset hashes, dimensions, and final-file hashes. It omits raw profile records, contact details, prompts, and machine paths.

After portraits and banner photographs are AI-edited. These independent design examples do not imply affiliation, endorsement, live-profile adoption, or improved business results. The repository’s code license does not grant rights to people’s likenesses, third-party marks, or reference designs.
